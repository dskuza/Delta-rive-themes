# Repository guidance

For theme creation or changes to artwork, layouts, input bindings or theme
packaging, read [SKILLS.md](SKILLS.md) and follow the linked
[create-delta-rive-theme skill](.agents/skills/create-delta-rive-theme/SKILL.md).
Its references describe the current runtime contract and authoring workflow.
For unrelated work, use the relevant repository files directly.

Existing designs and default controller positions are examples, not mandatory
styles. Keep generated `Dist/` exports, build products and captures ignored;
preserve editable sources, assets and their licenses. Respect the user's task
and the assistant's own execution permissions when building, importing or publishing.
